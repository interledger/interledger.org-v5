<Paragraph>

This demo page gives editors and developers a compact preview of the content blocks available on foundation pages. The placeholder copy is intentionally specific enough to test typography, links, lists, inline emphasis, and longer sentences without implying that the details are final editorial content.

Blocks covered on this page:

- Paragraph (lists, links, footnotes)
- Split layout (image/video + text/quote)
- Profile grid
- Blockquote
- CTA strip
- PDF embed and video embed
- **Card grid** — all variants: Title, Resource, Info, Navigation
- Logo carousel

Use this paragraph to review standard prose spacing, inline formatting, and footnotes.[^foundation-demo]

[^foundation-demo]: Demo footnote for validating article-style references in a foundation page paragraph.

</Paragraph>

## Card grid

Foundation pages can use every Card Grid variant. Each grid below uses one
variant only — never mix card types in the same grid.
