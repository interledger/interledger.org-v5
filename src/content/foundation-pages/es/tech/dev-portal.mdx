<Paragraph>

El conjunto de tecnologías de Interledger es de código abierto, cuenta con documentación completa y puede utilizarse sin costo. Si desea operar una billetera, crear un nodo de red o leer las especificaciones, este es el punto de partida.

Los protocolos, los estándares, la API de Open Payments y las herramientas basadas en ellos se desarrollan de forma abierta. Cualquier persona puede leer el código, ejecutarlo, proponer cambios y contribuir.

</Paragraph>

<CardGrid title="Por dónde comenzar" ariaLabel="Puntos de partida para desarrollar soluciones con Interledger" variant="Title" columns="Two">
<TitleCard heading="Open Payments" buttonUrl="https://openpayments.dev/es/" buttonText="Documentación de Open Payments" buttonExternal={true} secondButtonUrl="https://github.com/interledger/open-payments" secondButtonText="Repositorio de Open Payments" secondButtonExternal={true}>

Open Payments es un estándar de API abierta que pueden aplicar las entidades de servicios de cuentas para facilitar la interoperabilidad en la configuración y realización de pagos para diferentes casos de uso.

</TitleCard>
<TitleCard heading="Rafiki" buttonUrl="https://rafiki.dev/es/" buttonText="Documentación de Rafiki" buttonExternal={true} secondButtonUrl="https://github.com/interledger/rafiki" secondButtonText="Repositorio de Rafiki" secondButtonExternal={true}>

Rafiki es un software de código abierto que ofrece a una Entidad de Servicio de Cuentas una solución eficiente para habilitar la funcionalidad de Interledger en las cuentas de sus usuarios.

</TitleCard>
<TitleCard heading="Especificaciones" buttonUrl="/es/developers/rfcs/interledger-protocol/" buttonText="Documentación de las especificaciones" buttonExternal={true} secondButtonUrl="https://github.com/interledger/rfcs" secondButtonText="Repositorio de las especificaciones" secondButtonExternal={true}>

El Protocolo Interledger (ILP) es un protocolo abierto y neutral para transferir dinero basado en TCP/IP, diseñado para enviar paquetes de dinero entre diferentes registros contables.

</TitleCard>
<TitleCard heading="Herramientas de prueba" buttonUrl="/es/tech/test-tools/" buttonText="Test Tools" buttonExternal={false} secondButtonUrl="https://github.com/interledger/testnet" secondButtonText="Repositorio de Testnet" secondButtonExternal={true}>

Cree una billetera de prueba, realice una compra simulada y reproduzca un flujo de pago completo, desde la solicitud hasta la aprobación. También puede probar sus propias integraciones en Test Network (Testnet), una red Interledger abierta que funciona con dinero de prueba.

</TitleCard>
</CardGrid>

## Desarrolle soluciones con nosotros

Puede desarrollar soluciones con Interledger por su cuenta, con la documentación abierta, los repositorios, las herramientas de prueba y la comunidad. También puede hacerlo con apoyo: Interledger Foundation financia, mediante sus programas de subvenciones, a equipos e instituciones que integran el conjunto de tecnologías o implementan Open Payments.
