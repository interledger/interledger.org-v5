## Step 3 - Build & test

Hands-on tools to make a payment actually happen.

</Paragraph>

<CardGrid ariaLabel="Step 3 resources" variant="Title" columns="Two">
<TitleCard heading="Interledger Test Wallet" buttonUrl="https://wallet.interledger-test.dev" buttonText="Get a Test Wallet" buttonExternal={true}>

Simulates a financial service provider with Interledger enabled. Sign up, go
through a KYC flow, and hold a play-money balance to send and receive
payments using wallet addresses. It also exposes the Open Payments APIs so
third parties can initiate payments.

</TitleCard>
<TitleCard heading="Supporting GitHub repositories" buttonUrl="https://github.com/interledger" buttonText="View our GitHub" buttonExternal={true}>

Example scripts for sending payments, a library of prewritten code snippets
for Visual Studio Code, and Node SDK snippets that work with the Interledger
Test Wallet. For PHP, there are also the PHP Open Payments SDK and Open
Payments PHP Snippets repositories. Together these make it easier to test,
integrate, and experiment with Open Payments in your project.

</TitleCard>
<TitleCard heading="Interledger Pay" buttonUrl="https://interledgerpay.com/" buttonText="Pay someone" buttonExternal={true}>

A working peer-to-peer payment client application.

</TitleCard>
<TitleCard heading="Interledger Boutique" buttonUrl="https://boutique.interledger-test.dev/" buttonText="Make a purchase" buttonExternal={true}>

An example eCommerce app for trying out an Open Payments checkout flow end to
end.

</TitleCard>
</CardGrid>
