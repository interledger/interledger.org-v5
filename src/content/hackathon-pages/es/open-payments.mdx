## Paso 3 - Construye y prueba

Herramientas prácticas para que un pago realmente suceda.

</Paragraph>

<CardGrid ariaLabel="Recursos del paso 3" variant="Title" columns="Two">
<TitleCard heading="Interledger Test Wallet" buttonUrl="https://wallet.interledger-test.dev" buttonText="Consigue una Test Wallet" buttonExternal={true}>

Simula un proveedor de servicios financieros con Interledger habilitado.
Regístrate, completa un flujo de KYC y mantén un saldo de dinero de práctica
para enviar y recibir pagos usando direcciones de wallet. También expone las
APIs de Open Payments para que terceros puedan iniciar pagos.

</TitleCard>
<TitleCard heading="Repositorios de apoyo en GitHub" buttonUrl="https://github.com/interledger" buttonText="Ver nuestro GitHub" buttonExternal={true}>

Scripts de ejemplo para enviar pagos, una biblioteca de fragmentos de código
listos para usar en Visual Studio Code y snippets del Node SDK que funcionan
con la Interledger Test Wallet. Para PHP, también están los repositorios PHP
Open Payments SDK y Open Payments PHP Snippets. En conjunto, facilitan probar,
integrar y experimentar con Open Payments en tu proyecto.

</TitleCard>
<TitleCard heading="Interledger Pay" buttonUrl="https://interledgerpay.com/" buttonText="Paga a alguien" buttonExternal={true}>

Una aplicación cliente de pagos peer-to-peer funcional.

</TitleCard>
<TitleCard heading="Interledger Boutique" buttonUrl="https://boutique.interledger-test.dev/" buttonText="Haz una compra" buttonExternal={true}>

Una app de comercio electrónico de ejemplo para probar un flujo de pago de
Open Payments de principio a fin.

</TitleCard>
</CardGrid>
