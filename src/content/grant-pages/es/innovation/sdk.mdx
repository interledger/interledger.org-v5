### **Temas y financiamiento en 2026**

- Compatibilidad con Grant Negotiation and Authorization Protocol (GNAP), definido en [RFC 9635](https://www.rfc-editor.org/rfc/rfc9635), como [esquema de seguridad](https://spec.openapis.org/oas/latest.html#security-scheme-object) en [OpenAPI Specification](https://www.openapis.org/).
- Compatibilidad con GNAP en el [generador de SDK Kiota](https://github.com/microsoft/kiota).
- Compatibilidad con el lenguaje Ruby en el generador de SDK Kiota.
- Compatibilidad con Arazzo Specification en el generador de SDK Kiota.

### **Acerca de Open Payments**

Open Payments es una API HTTP universal para iniciar y autorizar un pago en cualquier red de pagos. Cualquier proveedor de servicios financieros puede implementar la API de Open Payments para que sus clientes puedan utilizar Open Payments. Luego, los sitios web y las aplicaciones integran Open Payments como clientes de la API para facilitar los pagos en nombre de sus consumidores.
