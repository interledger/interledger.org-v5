### **Temas y financiamiento en 2026**

- Compatibilidad con Grant Negotiation and Authorization Protocol (GNAP), definido en [RFC 9635](https://www.rfc-editor.org/rfc/rfc9635), como [esquema de seguridad](https://spec.openapis.org/oas/latest.html#security-scheme-object) en [OpenAPI Specification](https://www.openapis.org/) (hasta $25 000)
- Compatibilidad con GNAP en el [generador de SDK Kiota](https://github.com/microsoft/kiota) para TypeScript, PHP, Python y Go (hasta $10 000 por lenguaje)
- Compatibilidad con los lenguajes [Rust](https://github.com/microsoft/kiota/issues/4436) y Ruby en el generador de SDK Kiota (hasta $25 000 por lenguaje)
- Bibliotecas de software para [RFC 9421](https://www.rfc-editor.org/rfc/rfc9421.html)[HTTP Message Signatures](https://httpsig.org/) (hasta $5000 por lenguaje)
- Documentación de los flujos de Open Payments en [Arazzo Specification](https://www.openapis.org/arazzo-specification) (hasta $1000)
- Compatibilidad con Arazzo Specification en el generador de SDK Kiota (hasta $25 000)
- Compatibilidad con [RFC 9635 en curl](https://github.com/curl/curl/discussions/13376) (hasta $10 000)

### **Acerca de Open Payments**

Open Payments es una API HTTP universal para iniciar y autorizar un pago en cualquier red de pagos. Cualquier proveedor de servicios financieros puede implementar la API de Open Payments para que sus clientes puedan utilizar Open Payments. Luego, los sitios web y las aplicaciones integran Open Payments como clientes de la API para facilitar los pagos en nombre de sus consumidores.
