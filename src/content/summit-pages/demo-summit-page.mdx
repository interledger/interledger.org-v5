The Summit demo page mirrors the foundation block set while running inside the
microsite theme. Use it to review contrast, spacing, and dark-background
treatments for body text, cards, links, and footnotes.[^summit-demo]

Blocks covered on this page:

- Paragraph, split layout, profile grid, blockquote
- CTA strip, PDF embed, video embed
- **Card grid** — all variants: Title, Resource, Info, Navigation
- Logo carousel

## Event card

Summit pages can use a full-width **Event card** (When, Where, optional Apply).
One card at a time; without Apply, the two columns expand to fill the width.

</Paragraph>
