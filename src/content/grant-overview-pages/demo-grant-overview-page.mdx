## Dynamic zone blocks

This demo grant overview covers every block available on the overview template.
Placeholder copy is realistic enough to exercise typography, spacing, and CTAs
without implying live program details.[^overview-demo]

Included body blocks:

- Paragraph
- Split layout
- Number tiles
- Card grid (Title, Resource, Info, Navigation)
- Blockquote
- Video embed
- Image block
- In-body CTA strip
- Logo carousel
